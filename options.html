Safari Gemini Form Assistant

On a Google Form, press ⌘ + Shift + U to process unanswered questions. Each question now has its own clickable status button: ✦ ready, ⟳ processing, ✓ filled, ! failed. Hover the button for details.

Get an API key from Google AI Studio. Stored in Safari extension-local storage.

Website access: Safari must allow this extension to access docs.google.com and generativelanguage.googleapis.com. Review in Safari → Settings → Extensions → Edit Websites. If you update the extension, refresh the form. Answers are not submitted automatically. Text/options and any question image are sent to Gemini for processing; review responses.

Some Google Forms layouts can change. Red ! buttons show local errors on hover, including network or rate-limit problems. Re-click an individual status button to retry or overwrite just that question.
